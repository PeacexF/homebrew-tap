# PeacexF Tap

## How do I install these formulae?

`brew install peacexf/tap/<formula>`

Or `brew tap peacexf/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "peacexf/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
